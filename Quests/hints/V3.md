# Hints · V3 · Agent Guardrails

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## start_safe
1. Balance 50 is at least 0, and spent 0 is within the budget of 100. Lean can check concrete numbers itself.
2. `decide` (or `unfold Safe start budget` then `norm_num`).

## no_guard_unsafe
1. Everything here is a concrete number, so Lean can run the agent and check the result, just like the `#eval`.
2. `decide`

## guardAI_jailbreak
1. `guardAI` checks each payment against the budget on its own, never the running total. And the agent can deposit money first, so the balance isn't the obstacle.
2. Deposit enough, then make two payments that are each under 100 but add up to more than 100.
3. `exact ⟨[.deposit 100, .pay 60, .pay 60], by decide⟩`

## blockAll_safe
1. Nothing ever runs, so the state never changes. Induction on the list of actions.
2. `induction actions with | nil => intro s hs; exact hs | cons a as ih => ...`
3. Cons case: `intro s hs`, then `simp only [runWith, blockAll]` (the `if` with `false` disappears), then `exact ih s hs`.

## guard_is_helpful
1. Unfold `guard` for a payment: it's "n ≤ balance AND spent + n ≤ budget", and you have both as hypotheses.
2. `simp [guard, h1, h2]`

## guard_step_safe
1. Two kinds of action. A deposit only adds money. A payment that `guard` approved was covered by the balance and keeps the total within budget.
2. `unfold Safe at *`, then `cases a with | deposit n => ... | pay n => ...`.
3. Deposit: `simp [step]; omega`. Pay: `simp [guard] at hg` (unpacks what the guard checked), then `simp [step]; omega`.

## shielded_step_safe
1. Either the guard approved (use Step 1) or it blocked (the state didn't change).
2. `split_ifs with h`, then `· exact guard_step_safe s a hs h` and `· exact hs`.

## guard_always_safe
1. Same shape as `blockAll_safe`: induction on the actions, and the `∀ s` lets you use the induction hypothesis on whatever state comes next.
2. Cons case: `intro s hs`. Unfolding, `runWith guard s (a :: as)` is `runWith guard (if guard s a then step s a else s) as`.
3. `exact ih _ (shielded_step_safe s a hs)`
