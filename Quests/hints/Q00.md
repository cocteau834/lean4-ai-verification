# Hints · Q00 · Orientation

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## compute
1. Concrete numbers only, so let Lean calculate.
2. `norm_num` (or `rfl`, or `decide`: all three work here).

## use_it
1. `key` is a function from `5 < n` to `n ≠ 0`, and you have `h : 5 < n`.
2. `exact key h`

## swap_and
1. Split `h` into its two halves, then build the "and" in the other order.
2. `obtain ⟨h1, h2⟩ := h` then `exact ⟨h2, h1⟩`

## two_cases
1. Same as the first case, but with `h1`.
2. `rw [h1]` then `norm_num`

## substitute
1. After the rewrite the goal is (b + 2) + (b + 2) = 2 * b + 4. Which autopilot proves identities?
2. `ring` (or `omega`)

## witness
1. What number plus 3 is 10?
2. `use 7`

## expand
1. It's an identity of +, × and ^.
2. `ring`

## squeeze
1. It follows linearly from h1 and h2: x < y and 0 < x give x < y + y.
2. `linarith`

## find_it
1. It's a known fact about primes. Let Lean search, or use the `#check` line above.
2. `exact?`, which finds `Nat.Prime.two_le hp`. (So does `exact hp.two_le`.)

## boss
1. Which c works? a = b + 2, so c = b + 1. Then you need both parts of the ∧.
2. Build everything at once with `⟨witness, proof1, proof2⟩`. Both proofs are whole-number arithmetic.
3. `exact ⟨b + 1, by omega, by omega⟩`
