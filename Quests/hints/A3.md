# Hints · A3 · Build a Mini-Prover

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## mp1
1. It's a library fact about lists.
2. `simp`

## mp2
1. It's (x − 1)² in disguise.
2. `nlinarith [sq_nonneg (x - 1)]`

## mp3
1. Induction on n; unfold `countdown` in the step.
2. `induction n with | zero => rfl | succ k ih => simp [countdown, ih]`

## mp4
1. Induction, using (k+1)³ + 2(k+1) = (k³ + 2k) + 3(k² + k + 1).
2. Step: `obtain ⟨m, hm⟩ := ih`, `refine ⟨m + k ^ 2 + k + 1, ?_⟩`, rewrite with that identity (proved `by ring`) and `hm`, then `ring`.

## mp5
1. Induction on the list. In the cons case the definition has an `if`, so split on it.
2. `induction l with | nil => simp [insertSorted] | cons y ys ih => ...`
3. Cons case: `simp only [insertSorted]` then `split_ifs <;> simp [ih]`.

## mp6
1. (a − b)² + (b − c)² + (c − a)² ≥ 0.
2. `nlinarith [sq_nonneg (a - b), sq_nonneg (b - c), sq_nonneg (c - a)]`

## mp7
1. Same shape as mp5: induction on the list, then split the `if`.
2. `induction l with | nil => simp [insertSorted] | cons y ys ih => simp only [insertSorted]; split_ifs <;> simp [ih]`

## mp8
1. If x² = 2 then |x| = √2, which would make √2 rational.
2. Prove `((|x| : ℚ) : ℝ) = Real.sqrt 2` using `Real.sqrt_sq`, then `exact irrational_sqrt_two (Set.mem_range.mpr ⟨|x|, hx⟩)`.
