# Hints · Q07 · Red-Team the Grader

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## fake_axiom
1. An `axiom` is a statement Lean accepts without any proof at all.
2. Just above the theorem, add `axiom cheat : (2 : ℕ) + 2 = 5`. Then the proof is `exact cheat`.

## fake_hijack
1. Make `+` mean something else, but only inside this section. What operation turns 2 and 3 into 6?
2. On the ✏️ line: `local instance : Add ℕ := ⟨Nat.mul⟩`. Then the proof is `decide`.

## fake_native
1. `native_decide` asks the compiled code for the answer instead of having the kernel check it.
2. `native_decide`

## fake_statement
1. The engine only checks that a theorem called `fake_statement` still exists, not what it says.
2. Change the statement to something true, e.g. `¬ Nat.Prime 91`, and prove it with `norm_num` (91 = 7 × 13).

## hijack_exposed
1. Out here, `+` is ordinary addition again, and 2 + 3 is 5.
2. `decide`

## lie_is_false
1. What does the definition of `lie` actually say?
2. `rfl`

## native_breaks_math
1. You have `fake_native : lie = true` and `lie_is_false : lie = false`. Chain them together.
2. `have h := fake_native.symm.trans lie_is_false` gives you `h : true = false`.
3. Then `exact Bool.noConfusion h`, which says two different constructors can never be equal.
