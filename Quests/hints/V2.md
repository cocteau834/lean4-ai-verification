# Hints · V2 · Vericoding

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## wrongDedup
1. The AI's spec only asks for "no duplicates". Which list has no duplicates no matter what?
2. The empty list. Write a function that ignores its input: `fun _ => []`.

## wrong_passes
1. After `intro l`, the goal is that your output has no duplicates. If your function returns `[]`, Lean can see that.
2. `intro l`, then `exact List.nodup_nil` (or `simp [wrongDedup]`).

## GoodSpec
1. A real dedup promises two things: no repeats, and the SAME elements as the input: nothing lost, nothing invented. Write both, for every input list.
2. Shape: `∀ l, (f l).Nodup ∧ ∀ x, x ∈ f l ↔ x ∈ l`.
3. So the line becomes `def GoodSpec (f : List ℕ → List ℕ) : Prop := ∀ l, (f l).Nodup ∧ ∀ x, x ∈ f l ↔ x ∈ l`.

## good_rejects_wrong
1. Suppose your spec held for `wrongDedup` and test it on a tiny list like `[1]`. Your spec says 1 must be in the output, but the output is empty.
2. `intro h`. Then (for the spec in the GoodSpec hint) `have := ((h [1]).2 1).mpr (by simp)` says `1 ∈ wrongDedup [1]`.
3. `simp [wrongDedup] at this` finishes: `1 ∈ []` is false.

## mem_dedupAI
1. Induction on `l`. In the step, `dedupAI (y :: ys)` is an `if`: either y is dropped (because it's in ys anyway) or kept.
2. `induction l with | nil => simp [dedupAI] | cons y ys ih => ...`. In the cons case: `simp only [dedupAI]` then `split_ifs with h`.
3. Kept case: `simp [ih]`. Dropped case: the goal is `x ∈ dedupAI ys ↔ x ∈ y :: ys`. Use `rw [ih, List.mem_cons]`, then `constructor`. One direction is `Or.inr`; for the other, `rintro (rfl | hx)` and use `h` when x = y.

## nodup_dedupAI
1. Induction again, same split. When y is dropped, the induction hypothesis is exactly the goal. When y is kept, you need "y is not in the rest", and the rest is `dedupAI ys`.
2. `List.nodup_cons` says `(a :: l).Nodup ↔ a ∉ l ∧ l.Nodup`. So in the kept case, `exact List.nodup_cons.mpr ⟨?_, ih⟩`.
3. The missing piece is `y ∉ dedupAI ys`. Lemma 1 turns that into `y ∉ ys`, which is `h`: `by rwa [mem_dedupAI]`.

## good_accepts_AI
1. Your spec has (probably) two parts, and you just proved one lemma for each.
2. For the spec in the GoodSpec hint: `intro l`, then `exact ⟨nodup_dedupAI l, fun x => mem_dedupAI x l⟩`.

## spec_pins_length
1. Two lists with no repeats and the same elements are rearrangements of each other (a "permutation"), and rearranging doesn't change length.
2. First prove `have hp : (f l).Perm (g l)`. `List.perm_ext_iff_of_nodup` turns that into "same elements", given that both lists have no repeats.
3. `have hp : (f l).Perm (g l) := by rw [List.perm_ext_iff_of_nodup (hf l).1 (hg l).1]; intro x; rw [(hf l).2 x, (hg l).2 x]`, then `exact hp.length_eq`.
