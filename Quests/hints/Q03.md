# Hints · Q03 · Induction Dojo

Spoilers! Use `python3 scripts/expedition.py hint <puzzle>` instead. It reveals one hint at a time and logs it for the Game Master.

## len_app
1. Induct on xs. Empty case: app [] ys is just ys. Cons case: app (x :: xs) ys = x :: app xs ys, which is one longer than app xs ys.
2. `induction xs with | nil => simp only [app, len]; omega | cons x xs ih => ...`
3. Cons case: `simp only [app, len, ih]` then `omega`.

## total_doubleAll
1. Same shape: unfold the definitions, use the induction hypothesis, then it's algebra.
2. `induction xs with | nil => simp [doubleAll, total] | cons x xs ih => ...`
3. Cons case: `simp only [doubleAll, total, ih]` then `ring`.

## len_rev
1. rev (x :: xs) = app (rev xs) [x]. Kata 1 tells you the length of an app.
2. `induction xs with | nil => simp [rev, len] | cons x xs ih => ...`
3. Cons case: `simp only [rev, len_app, len, ih]`.

## two_pow_ge
1. On paper: if k + 1 ≤ 2^k, then k + 2 ≤ 2^k + 2^k = 2^(k+1).
2. Base case: `simp`. Step: `rw [pow_succ]` (turns 2^(k+1) into 2^k * 2), then `linarith`.

## hanoi_formula
1. Unfold one step of `hanoi`, then use `ih` to get rid of 2^k.
2. Base: `simp [hanoi]`. Step: `rw [hanoi, pow_succ, ← ih]` then `ring`. (`← ih` rewrites right-to-left: it replaces 2^k by hanoi k + 1.)
