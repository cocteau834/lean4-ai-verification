## puzzle1

## puzzle2
1. You need a tactic that can test whether a number is prime.
2. `norm_num`

## puzzle3
1. The same tool can show a number is NOT prime: it finds a factor.
2. `norm_num` (2026 = 2 × 1013)

## triple

## puzzle4

2. `rfl` or `decide`
