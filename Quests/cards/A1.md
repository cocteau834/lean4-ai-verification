## 🎓 A1 · Bug Bounty: Checking AI-written code

**What you practiced.** Writing specs for AI-generated functions, proving the correct ones and refuting the buggy ones.

**On the job.** AI now writes a lot of production code. Research on *verified code generation* has the model produce code, a specification and a proof, so humans review the spec instead of every line. The natural-number subtraction bug you caught is a cousin of integer-overflow bugs that cause real outages.

**Level up.** Ask an AI to write a function (e.g. binary search on a list) plus its Lean spec. Is the spec actually what you wanted? Prove it, or break it.

**Résumé line.** “Specified and verified AI-generated functions in Lean 4; found bugs via formal counterexamples.”
